# CAN Message Simulator & Forgery Detector

## 🎯 목적
이 프로젝트는 차량 내 CAN 통신 구조를 이해하고, 비정상 메시지를 탐지하는 기초 보안 시스템을 구현하기 위해 만들어졌습니다.

## ⚙️ 기술 스택
- Python
- Random message generation
- Rule-based intrusion detection logic

## 🚦 탐지 조건
- ID 범위: 100 ~ 150
- Speed 범위: 0 ~ 250
- RPM 범위: 500 ~ 8000
